# 寒冰菇（国际版）1.1.1 · PvZ2 Gardendless 0.16.15

## 安装

1. 在 GP-Next 的「实验性」设置开启 JS Modding。
2. 在 Mods 页面依次导入并启用以下 ZIP。已安装同版 `pvzge.entities` 的玩家可以从第 2 个 ZIP 开始。
   - `1-pvzge.entities.zip`（实体框架 0.1.0）
   - `2-gzh.iceshroom.zip`（寒冰菇机制）
   - `3-gzh.iceshroom.content.zip`（寒冰菇内容）
3. 从 1.1.0 升级时，重新导入第 3 个 ZIP。从 1.0.0 升级时，重新导入第 2 和第 3 个 ZIP。重启游戏。在沙盒选择「寒冰菇（国际版）」。要在普通关卡使用，请载入存档并在 GP-Next 的「寒冰菇（国际版）」控制面板点解锁，随后重新进入关卡。

寒冰菇有独立的实体 ID，可以和 Gardendless 的植物及奶油生菜移植版一同启用。

## 1.1.1 修订

一级种子卡开局冷却为 8 秒，每次种植后冷却为 12 秒。

## 1.1.0 修订

- 株型按原版录像的格宽校准，草坪和拖放预览使用同一比例，草坪锚点取自 13.5.2 的 ArtCenter。
- 一级普攻查询同排脚下格与前一格。触发和命中都使用这个范围，每个命中目标各有一个原版近战特效。冰地板绘制在棋盘的冰地表层，位于植物下方。
- 能量豆按 0.8 秒间隔排程。冰刺保持正立，从目标格上空落下，落地时播放冲击动画并判定伤害和冻结。

## 来源和验证

卡面、本体的 5 段动作、4 套特效和 6 个声音事件取自国际版 13.5.2。ARM64 原版代码中，0x1e09b4c 计算近战网格范围，0x1e084a0 在命中目标坐标上应用偏移，0x1e08ab0 和 0x1e0b570 负责冰刺排程与生成。株型比例参考 11.0.1 的实战录像。 [国际版实战录像](https://www.bilibili.com/video/BV1Ju4y1c76h/)

Gardendless 0.16.15 沙盒验证了株型比例、同排前一格能命中、后方和邻排不吃近战伤害、特效以命中目标为基准，冰地板在植物下方，以及四枚保持正立的冰刺依次落地。

实装采用国际版一级数值。原始 1–10 级数值和冬青薄荷加成表保存在机制包中。冰刺的随机目标与空格补位按 Gardendless 的实体和棋盘接口实现。
